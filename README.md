This is made for the purposes of galactic photometry. 
Configure settings in parameters in order to define the galaxy you want to observe and pick suitible constraints in the star detector. 
NGC_2403 shot in V band is used as an example image.
There are plans to include a better way for this to be done (ie a .dat file reader) but this is the situation. Make note of the units (especially in the mass to light ratio
